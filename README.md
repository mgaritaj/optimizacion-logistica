# Optimización Logística

Aplicación web interactiva para estimar la ubicación óptima de un centro de distribución a partir de la ubicación de sus clientes y su volumen relativo de ventas.

El proyecto utiliza un algoritmo de descenso de gradiente para minimizar las distancias euclidianas ponderadas entre los clientes y el centro de distribución.

## Funcionalidades

- Selección de clientes directamente sobre un mapa.
- Asignación de nombre y volumen de ventas a cada cliente.
- Cálculo de la ubicación óptima del centro de distribución.
- Visualización del resultado sobre el mapa.
- Configuración de alpha, tolerancia e iteraciones máximas.
- Visualización de la convergencia del costo y del gradiente.
- Comparación entre diferentes valores de alpha.

## Tecnologías utilizadas

- Python
- Streamlit
- Folium
- Pandas
- PyProj
